# Code of Conduct

Author: Saad Kamal

Skywrite aims to be a respectful, learning-friendly open-source project.

## Expected Behavior

- Be kind and direct.
- Assume good intent.
- Keep technical criticism specific and actionable.
- Respect privacy and accessibility concerns.
- Help newcomers understand the project.

## Unacceptable Behavior

- Harassment or personal attacks
- Discriminatory language
- Publishing private information
- Dismissing security or privacy reports without review

## Enforcement

Saad Kamal may remove comments, close issues, or block contributors who violate this code of conduct.
